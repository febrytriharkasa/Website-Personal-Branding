ABOUT ME

Challenge

Sebagai lulusan Teknik Informatika dari Universitas 17 Agustus 1945 Surabaya, saya mengenali bahwa industri pengembangan web sangat kompetitif dan dinamis, yang memerlukan pembelajaran berkelanjutan, kemampuan beradaptasi dengan kerangka kerja modern, dan keterampilan pemecahan masalah yang kuat untuk menonjol.

Action

Untuk menjawab tantangan ini, saya mendalami penguasaan teknologi pengembangan web modern, dengan fokus pada bahasa dan framework utama seperti PHP (Laravel), JavaScript, HTML, CSS, dan MySQL. Saya secara aktif membangun aplikasi web yang fungsional serta berkolaborasi dalam berbagai proyek untuk mengasah kemampuan coding, desain sistem, dan kerja sama tim saya.

Result

Melalui perjalanan ini, saya telah berhasil mengembangkan sistem manajemen berbasis web dan aplikasi web interaktif yang menunjukkan kemampuan teknis, pola pikir logis, serta perhatian saya terhadap pengalaman pengguna. Pengalaman praktis ini telah memperkuat minat saya dalam pengembangan web sekaligus membentuk landasan kompetensi saya sebagai Junior Web Programmer yang dapat diandalkan.
